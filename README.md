# Baale Channel Join Bot

ربات مدیریت عضویت کانال در پیام‌رسان بله با رضایت صریح کاربر.

## ویژگی‌ها

- دریافت دستور `/start`
- نمایش پیام خوش‌آمدگویی
- دکمه Inline برای تأیید عضویت
- ارسال لینک دعوت رسمی کانال فقط بعد از رضایت کاربر
- ذخیره اطلاعات کاربران در SQLite
- ثبت زمان Start، رضایت و ارسال لینک
- لاگ کامل فعالیت‌ها و خطاها
- تنظیمات از طریق فایل `.env`

## نصب

```bash
cd Baale_Channel_Join_Bot

python3.11 -m venv venv
source venv/bin/activate   # لینوکس / مک
# ویندوز: venv\Scripts\activate

pip install -r requirements.txt
```

## تنظیمات

فایل `.env` از قبل ساخته شده و توکن داخلش قرار دارد.

**حتماً `CHANNEL_ID` را با آیدی واقعی کانال خودتان عوض کنید.**

### نحوه گرفتن CHANNEL_ID

1. ربات را به عنوان ادمین به کانال اضافه کنید.
2. یک پیام در کانال بفرستید.
3. این آدرس را در مرورگر باز کنید (توکن را جایگزین کنید):
   ```
   https://tapi.bale.ai/bot387755932:TLitUpjrPJire3ZLF6EiZykAqPg2EfD7lWk/getUpdates
   ```
4. مقدار `chat.id` مربوط به کانال را کپی کنید و در `.env` بگذارید.

## اجرا

```bash
python main.py
```

## نکته مهم

- ربات کاربران را اجباری به کانال اضافه نمی‌کند.
- عضویت فقط از طریق لینک دعوت و اقدام خود کاربر انجام می‌شود.
- ربات باید در کانال ادمین باشد.
